## Como instalar

1. **Instale as dependências**

   ```bash
   npm install ogl
   ```

2. **Crie src/components/Prism.tsx** Copie o conteúdo de `src/Prism.tsx` deste repositório.
3. **Use na página**

   ```tsx
   <Prism animationType="rotate" timeScale={0.5} scale={3.6} glow={1} />
   ```
